🛠️ IT Toolkit - Diagnóstico y Mantenimiento
⚠️ Estas utilidades requieren permisos de administrador. Se abrirá una ventana CMD visible.
SFC /SCANNOW — Comprueba la integridad de los archivos protegidos del sistema y repara los dañados.

DISM — Repara la imagen de Windows (requiere conexión a internet para descargar archivos desde Windows Update).

cleanmgr — Ejecuta el Liberador de espacio en disco oficial de Windows para eliminar archivos temporales, papelera de reciclaje y memoria caché del sistema.
